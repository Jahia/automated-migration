## 6. Generic lessons (anti-overfit — each from a real incident)

1. **Verify against reality, never trust "operation successful".** Deploy returns `{}` on
   success AND failure; publish no-ops in 1 ms; the P6.3-bis agent reported "home loaded"
   but only home was loaded — a reality query caught it. Every mutation → a reality assertion.
2. **A tolerant belt + an outage = a silent hole paid 3 gates later.** Strict end-of-phase
   belts (A1) fail fast.
3. **Fidelity ceiling on marketing sites is dominated by metric noise, not infidelity.**
   Rule-35: reference JS hides sections the crawl captured; a constant ~+322px header delta
   cascades pixel loss. The JS-hydrated symmetric-capture experiment DISPROVED the "just let
   JS run" hypothesis honestly (mirror & live reach genuinely different JS states).
4. **discoverasr is the WORST case for modularity** (0% baseline, widget-dominated) — the
   recognizer works; the site is the hard part. Prove the thesis on card-heavy sites.
5. **Cloned-slide dedup is the crux of carousel promotion** — normalize the slide signature
   (strip state tokens), drop clones by marker union (aria-hidden / *-duplicate / dup index).
6. **Captured site content carries third-party secrets** — the harness must NEVER commit it
   (→ doctrine #4, and WORKFLOW-IMPROVEMENTS 1.8).
7. **Self-gating agents are the leverage** — objective STOP criteria + report at forks; the
   P6.3 self-gate correctly stopped a bad deploy.
