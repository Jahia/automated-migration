## 3. Apprentissages (leçons génériques, chacune payée en vrai)

- **L1 — Ne jamais accuser le modèle sans timestamps.** « DeepSeek lit au lieu d'agir »
  était FAUX : transcript horodaté = 3 s/tour, comportement conforme au contrat
  AGENTS.md, puis hang harnais. Deux minutes de forensique ont tranché ce que trois
  retries avaient maquillé en flake. (Corollaire de l'échelle d'autorité : les
  narrations — y compris les miennes — ne valent rien contre un timestamp.)
- **L2 — Un harnais interactif n'est pas un harnais headless.** La garde « ask » (défaut
  opencode) sur `*.env` supposait un humain devant un TUI ; en headless, personne ne
  répond → deadlock silencieux, et l'auto-approve du moteur dépendait d'un event feed
  jamais garanti. Motivation racine de la dépose P5.5.
- **L3 — `MaxRAMPercentage` sans limite conteneur = heap dimensionné sur la VM entière.**
  8.3 GB × 80 % ≈ 6.6 GB de heap « autorisé » dans un espace partagé avec un 2e Jahia →
  SIGKILL au premier burst. Un `-Xmx` explicite prime et borne.
- **L4 — Le travail mécanique n'appartient pas à une session d'agent.** Une deadline de
  session (600 s) ne peut pas héberger un job long ; une commande connue au moment du
  plan est exécutée par le moteur (engine-exec), le LLM n'y ajoute que du risque.
- **L5 — Une ceinture tolérante en phase laisse passer des trous que les gates aval
  paient.** min-ratio 50 %/page a validé un load à 72.8 % ; G2 a payé. La
  défense-en-profondeur a fonctionné (rien n'a échappé), mais tard → amélioration A1.
- **L6 — Les retries transport ne couvrent pas un outage de plusieurs minutes.** Les
  items tombés pendant les ~3 min d'OOM ont été définitivement sautés (~685 nœuds).
  Remède : re-run idempotent (rollback) ; prévention : A2.
- **L7 — Les nœuds géants (skeleton ~200 KB, 18 champs) publient/rendent en > 45 s.**
  Réel pour les éditeurs aussi ; argument matériel pour P6 (chrome-lift). La barre G2
  n'a pas bougé : le finding est honnête et ira à l'exceptions_review.
- **L8 — Deux acteurs sur un même index git = commits balayés.** `git commit` sans
  pathspec a embarqué le staging d'un agent concurrent. Règle : toujours
  `git commit -- <paths>` quand l'arbre est partagé (réparé par réécriture prouvée
  bit-identique par hash d'arbre).
- **L9 — Les vérifications se font dans l'environnement canonique.** 15 « échecs »
  pytest = python système sans pytest-asyncio ; le `.venv` moteur (139/139) est la vérité.
- **L10 — La discipline de rapport ne survit pas aux sessions sans machinerie.** D'où :
  hook SessionStart (détection de run actif → injection de la directive) + heartbeat
  auto-réarmé 5 min + watcher ceinture 2 min (JSONL) + panneau cockpit auto-poll.
- **L11 — Le `cwd` persistant entre commandes shell est un piège** (pathspec raté,
  `migration-orchestrator/migration-orchestrator/` fantôme d'hier) : chemins absolus.
