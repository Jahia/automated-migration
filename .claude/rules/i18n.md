# i18n Rules

Auto-loaded when touching locale files or `.properties` resources. Full reference: `.agents/context/jahia-i18n-patterns.md`.

## Two-Tier i18n System

| Tier | Files | Purpose |
|---|---|---|
| CND labels | `settings/resources/<module>.properties` (EN + FR) | Labels for content types, properties, views in jContent editor |
| Front-end UI | `settings/locales/en.json` + `fr.json` | Labels for UI components, actions, dialogs |

**Both tiers are mandatory.** A module that ships CND types must ship both `.properties` files. A module with UI labels must ship both `.json` locale files.

## CND Label Key Conventions

The `:` namespace separator becomes `_` in all `.properties` keys.

```properties
# Content type label — namespace_TypeName=Human label
euint_alertBanner=Alert Banner

# Property label — namespace_TypeName.ns_propName=Label
euint_alertBanner.eui_level=Level
euint_alertBanner.eui_level.ui.tooltip=Controls the alert severity displayed to users.

# Choicelist[resourceBundle] value — namespace_TypeName.ns_propName.constraintValue=Display label
euint_alertBanner.eui_level.info=Information
euint_alertBanner.eui_level.warning=Warning
euint_alertBanner.eui_level.error=Error
euint_alertBanner.eui_level.success=Success

# View label
namespace_MyType.default.label=Default View
namespace_MyType.small.label=Small View
```

> Always use `(string, choicelist[resourceBundle])` for fixed-value dropdowns — never bare `(string, choicelist)`. The bare form shows raw stored values instead of labels in the editor.

## Front-End Locale Key Conventions

```json
{
  "myModule": {
    "actions": {
      "create": "Create Item",
      "delete": "Delete Item"
    },
    "labels": {
      "title": "Title",
      "noResults": "No results found"
    },
    "errors": {
      "notFound": "Item not found"
    }
  }
}
```

## Non-Negotiable Rules

- Every module ships **at minimum EN + FR** — no exceptions.
- Never hardcode display strings in `.tsx` or `.java` files — all user-visible text goes through the i18n system.
- CND property names in `.properties` must exactly match the property names in `definition.cnd`.
- FR translations must be real translations — do not copy EN values as placeholders and ship.
- Use `useTranslation` from `react-i18next` in front-end components (available via `@jahia/javascript-modules-library`).
- **Every property MUST have a `.ui.tooltip` entry — this is a review blocker if missing.**
  - HTML is accepted and encouraged: `<b>`, `<br/>`, `<a href="..." target="_blank">`, `<i>`, `<ul><li>`
  - Tooltip pattern: `ns_type.property.ui.tooltip=<b>Field name</b> — what it does.<br/>Constraints or examples.`
  - Translate tooltips in every locale file (`_fr.properties`, etc.) — not just the EN default.

## File Locations

```
settings/
  resources/
    <module>.properties       # English CND labels (default)
    <module>_fr.properties    # French CND labels
  locales/
    en.json                   # English UI labels
    fr.json                   # French UI labels
```
